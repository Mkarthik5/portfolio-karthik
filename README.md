## Getting Started

```bash
# Clone the repo
git clone https://github.com/Mkarthik5/portfolio-karthik.git
cd portfolio-karthik

# Install dependencies
npm install

# Start dev server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

---

## Build & Deploy

```bash
# Build for production
npm run build

# Preview production build
npm run preview
```

Deployed on **Vercel** — auto-deploys on every push to `main`.
